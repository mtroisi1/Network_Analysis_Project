# Network Analysis Project

This repository contains working network analysis for my thesis project on community structure in microbial datasets.

# # Installation and Setup

Clone this repository. In Terminal navigate to project folder. Create conda environment from `environment.yml`:

```bash
conda env create -f environment.yml --name network_analysis_env
```

Activate the conda environment and launch Jupyter Notebook

```bash
conda activate network_analysis_env
jupyter notebook
```
Open `ModularityProjectNotebook.ipynb` and run.
